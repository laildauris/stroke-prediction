# 🧠 Centre Neurologique – Prédiction du Risque d'AVC
## Dauris – Bouchra – Amine

Application de prédiction du risque d'AVC basée sur le modèle hybride **TabNet-MLP**.

## Déploiement
[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/laildauris/stroke-prediction/main/app.py)

## Fonctionnalités
- 🔐 Authentification utilisateur
- 🔮 Prédiction avec modèle hybride TabNet-MLP
- 🔍 Explication LIME des prédictions
- 📊 Dashboard clinique interactif
- 📄 Génération de rapports PDF
- 💾 Stockage des prédictions
